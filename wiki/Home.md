# OpenGridX

A high-performance React DataGrid, free and MIT-licensed: virtualization for 100k+ rows, filtering, sorting, editing, pinning, row grouping and tree data, aggregation and pivot, master-detail, cell spanning, and CSV / Excel / PDF export. No UI-framework dependencies; React 18 and 19.

```bash
npm install @opencorestack/opengridx
```

**[Live demo](https://opencorestack.github.io/OpenGridX/)** · **[npm](https://www.npmjs.com/package/@opencorestack/opengridx)** · **[Repository](https://github.com/OpenCoreStack/OpenGridX)**
